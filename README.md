# 🪔 New Yuwa Boys Mandal Book (न्यू युवा बॉईज मंडळ बुक)

> **अधिकृत डिजिटल जमा-खर्च, वर्गणी व ताळेबंद प्रणाली**
> **मंडळ:** न्यू युवा गणेश मंडळ, केऱ्हाळे बु. (New Yuwa Ganesh Mandal, Kerhale Bk.)
> **वर्ष:** भव्य सार्वजनिक गणेशोत्सव २०२६

---

## 🌟 Key Features

### 1. ⚡ Live Transparency Dashboard
- Real-time financial statistics: **एकूण जमा (Total Collections)**, **एकूण खर्च (Total Expenses)**, **शिल्लक (Net Available Balance)**.
- **Cash in Hand vs Bank Balance** breakdown.
- **सर्वाधिक देणगीदार (Top Donors Leaderboard)** with Gold, Silver, and Bronze recognition.
- **खर्चाचे वर्गीकरण (Expense Distribution Chart)**.

### 2. 📱 Digital WhatsApp Receipt Engine
- Sacred invocation: **॥ श्री गणेश प्रसन्न ॥**
- Header: **न्यू युवा गणेश मंडळ, केऱ्हाळे बु.**
- Official Receipt Number (`MB-2026-00101`) & Date.
- Donor name, address, phone number.
- Amount in digits and **Devanagari Marathi words** (उदा. *₹ २५,००० - पंचवीस हजार रुपये फक्त*).
- **1-Click WhatsApp Share**: Generates automated `wa.me` deep link.
- **High-Resolution Photo (PNG)** and **Printable PDF** downloads.
- Public online receipt verification URL: `/receipt/[id]`.

### 3. 💳 Dynamic 0% Fee UPI QR Code Generator
- Instant dynamic QR generated on-the-fly with `upi://pay?pa=newyuwaboys@upi&am={amount}&pn=न्यू युवा गणेश मंडळ, केऱ्हाळे बु.`.
- Direct mobile tap-to-pay button for Google Pay, PhonePe, and Paytm.

### 4. 📋 खर्च / व्हाऊचर व्यवस्थापन (Expense Vouchers)
- Categorized expenses: मंडप, श्रींची मूर्ती, विद्युत रोषणाई, ध्वनी / डीजे, महाप्रसाद, परवानग्या, विसर्जन, इतर.
- Auto-generated voucher numbers (`VCH-2026-001`).
- Multi-tier committee approvals (अध्यक्ष, खजिनदार).

### 5. 📑 Document Vault (सरकारी परवानग्या व NOC)
- Centralized permit repository (Police, Municipal, Fire NOC, Electricity, Insurance).

### 6. 📊 Charity Commissioner & AGM Audited Balance Sheet (ताळेबंद)
- **1-Click Audited Balance Sheet (ताळेबंद)** in official 2-column legal Marathi format (जमा बाजू vs खर्च बाजू).
- Signature blocks for President (अध्यक्ष), Secretary (सचिव), Treasurer (खजिनदार), and Auditor.
- **1-Click Excel Exports (`xlsx`)** for complete donation and expense registers.
- Daily WhatsApp summary broadcast generator for committee groups.
